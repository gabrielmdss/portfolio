# Portfolio — Gabriel Mendes

Portfólio pessoal de Gabriel Mendes, Desenvolvedor Full Stack.

Construído com **Angular 19** (componentes standalone) com **SSR / prerender**.

## Rodando localmente

```bash
npm install
npm start
```

Acesse `http://localhost:4200/`.

## Build

```bash
npm run build
```

Os arquivos são gerados em `dist/portfolio/` (`browser/` estático pré-renderizado e `server/` para SSR).

## Estrutura

```
src/components/
├── header/                    # Navegação
├── body/components/
│   ├── informacoes-pessoais/  # Sobre
│   ├── projetos/              # Projetos em destaque
│   ├── habilidades/           # Habilidades técnicas
│   └── vamos-conversar/       # Contato
└── footer/
```
